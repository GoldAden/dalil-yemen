## نظرة عامة

**دليل اليمن** تطبيق أندرويد أصلي مبني بـ **Kotlin + Jetpack Compose**، موجّه للمستخدم اليمني: يبحث عن المحلات والخدمات، ويتصفّحها حسب **المدينة** و**التصنيف**، ويعرض **الأماكن القريبة** عبر نظام تحديد المواقع عند موافقة المستخدم.

> **ملاحظة مهمة حول البيانات**
> المشروع **لا يحتوي على أي بيانات محلات حقيقية أو مُختلقة**، ولا على أي مفاتيح API وهمية.
> التطبيق يبنى ويعمل ويُثبَّت بالكامل، ويعرض حالة فراغ واضحة ومنظّمة في انتظار ربط مصدر بيانات حقيقي
> (قاعدة بيانات محلية أو خدمة خلفية). هذا مقصود: البنية هي الأساس، والبيانات تأتي لاحقاً من مصدر موثوق.

## الميزات

### الشاشة الرئيسية
- **شريط بحث** للوصول السريع إلى شاشة البحث.
- **شبكة الأقسام** بالتصنيفات المطلوبة:
  | القسم | المعرّف |
  |---|---|
  | المطاعم والمقاهي | `restaurants` |
  | المستشفيات والصيدليات | `health` |
  | محطات الوقود | `fuel` |
  | ورش الصيانة | `maintenance` |
  | محلات الجوالات والإلكترونيات | `electronics` |
  | المتاجر والأسواق | `stores` |
- **الأماكن القريبة مني**: تعرض المحلات الأقرب بعد الموافقة على إذن الموقع.
- **مقترحة**: قسم جاهز لعرض محتوى مميّز (يُملأ عند ربط المصدر).

### البحث والتصفية
- بحث نصي فوري بأي اسم أو خدمة.
- تصفية حسب **المدينة** (٢١ محافظة يمنية معرّفة) و**التصنيف** في الوقت نفسه.
- زر إعادة تعيين للفلاتر.

### شاشة تفاصيل المحل
تعرض كل الحقول المطلوبة عند توفّرها:
- الاسم والوصف.
- رقم الهاتف (مع إمكانية الاتصال المباشر).
- العنوان.
- ساعات العمل.
- الموقع على الخريطة (فتح في تطبيق الخرائط).
- الصور عند توفّرها (مع حالة واضحة عند عدم وجودها).
- زر مشاركة.

### التعامل مع إذن الموقع
- طلب الإذن بلُطف مع شرح واضح للسبب.
- **عند الرفض**: لا يتعطّل التطبيق؛ تُعرض رسالة، ويبقى البحث والتصفية يعملان بشكل كامل.
- معالجة حالات إضافية: خدمة الموقع مغلقة، أو تعذّر تحديد الموقع.
- استخدام الموقع **الأخير المعروف** فقط — دون تتبّع مستمر — لتوفير البطارية.

### الواجهة
- **عربية بالكامل مع دعم RTL** مفروض على مستوى تطبيق النصوص.
- تصميم حديث بـ Material 3، مع الوضع الفاتح والداكن.
- هوية بصرية: **أخضر `#0E6E5C`** + **ذهبي `#E0A526`**.
- دعم الإنجليزية (`values-en`) للمراجعة والتوسعة.

## طريقة البناء والحصول على APK

### الطريقة الأولى: GitHub Actions (بدون كمبيوتر) ⭐

لا تحتاج إلى تثبيت أي شيء على جهازك. كل عملية البناء تحدث على خوادم GitHub مجاناً.

1. أنشئ مستودعاً جديداً فارغاً على GitHub باسم `dalil-yemen`.
2. ارفع محتويات هذا المشروع إليه (من واجهة الموقع: **Add file → Upload files**).
3. اذهب إلى تبويب **Actions** في المستودع.
4. اختر سير العمل **«بناء تطبيق دليل اليمن»** ثم اضغط **Run workflow**.
5. انتظر انتهاء البناء (عادة ٤–٧ دقائق).
6. في صفحة التشغيل، انزل إلى قسم **Artifacts** ونزّل:
   - `dalil-yemen-debug-apk` — نسخة تجريبية متوقّعة للتثبيت والتجربة.
   - `dalil-yemen-release-apk` — نسخة الإصدار.
7. فُكّ ضغط الملف وستجد داخله `app-debug.apk` أو `app-release.apk`.

**لإنشاء إصدار (Release) رسمي:**
أنشئ وسم إصدار يبدأ بحرف `v` (مثل `v1.0.0`) وارفعه:

```bash
git tag v1.0.0
git push origin v1.0.0
```

سيقوم سير العمل تلقائياً ببناء نسخة الإصدار وإرفاقها في صفحة **Releases** للتحميل المباشر.

> **تنبيه أمني**: نسخة الإصدار الحالية موقّعة بمفتاح التطوير حتى تجهيز مفتاح إنتاجي.
> لا تضع كلمات مرور التوقيع أو التوكنات داخل الملفات — استخدم **Secrets** في إعدادات المستودع.

### الطريقة الثانية: البناء على جهازك

```bash
# 1) تأكد من JDK 17 ومن وجود Android SDK (platform 34 + build-tools 34.0.0)

# 2) أنشئ ملف local.properties وحدّد مسار الـ SDK
#    (على Windows: C:\\Users\\<اسمك>\\AppData\\Local\\Android\\Sdk)
echo "sdk.dir=/path/to/Android/Sdk" > local.properties

# 3) ابنِ النسخة التجريبية
./gradlew assembleDebug

# أو نسخة الإصدار
./gradlew assembleRelease
```

**مكان الملفات الناتجة:**

| النسخة | المسار |
|---|---|
| تجريبية | `app/build/outputs/apk/debug/app-debug.apk` |
| إصدار | `app/build/outputs/apk/release/app-release.apk` |

## التوسعة المستقبلية

صُمّم المشروع بحيث تكون كل إضافة لاحقة بسيطة ودون إعادة كتابة الواجهات.

### 1) ربط قاعدة بيانات أو خدمة خلفية

كل الشاشات تعتمد على واجهة واحدة فقط هي `PlaceRepository`. لإضافة مصدر بيانات:

1. أنشئ تنفيذاً جديداً للواجهة، مثال:
   - `RoomPlaceRepository` — قاعدة بيانات محلية داخل الجهاز.
   - `RemotePlaceRepository` — خدمة خلفية عبر الشبكة.
2. بدّل سطراً واحداً في `DalilRepositoryProvider` ليصبح التنفيذ الجديد هو المستخدم.

لا تحتاج لتعديل أي شاشة أو مكوّن واجهة. النموذج `Place` جاهز أصلاً بكل الحقول المطلوبة
(الاسم، الوصف، الهاتف، العنوان، المدينة، التصنيف، الإحداثيات، ساعات العمل، الصور).

### 2) الإعلانات المدفوعة

البنية تحتوي على طبقة منفصلة `Monetization` بتنفيذ مبدئي محايد (`NoOp`)، وعلى حقل
`isSponsored` في نموذج المحل. لإضافة شبكة إعلانات:

1. نفّذ الواجهة في `Monetization.kt` باستخدام الشبكة المختارة.
2. استبدل `NoOpMonetization` بالتنفيذ الجديد في نقطة التهيئة.
3. استخدم العائد `isSponsored` لتمييز المحلات المدفوعة بصرياً في القوائم.

### 3) الاشتراكات للمحلات

نفس المبدأ: أضف طبقة اشتراكات مستقلة، وأضف حقولاً للخطة والصلاحية في `Place`،
ثم اربطها بمنطق العرض — دون المساس بمصدر بيانات المحلات.

### 4) إضافة مدن أو تصنيفات

- المدن: أضف عنصراً إلى `YemenCities.all`.
- التصنيفات: أضف ثابتاً في `Categories` + نصاً في `res/values/strings.xml`.

## الأمان والخصوصية

- التطبيق **لا يجمع** أي بيانات شخصية ولا يرسلها إلى أي جهة.
- إذن الموقع **اختياري تماماً**، ويُستخدم فقط لترتيب الأماكن حسب القرب.
- لا يوجد أي مفتاح أو سر داخل الكود المصدري.
- لا يتم تتبّع الموقع بشكل مستمر أو في الخلفية.
